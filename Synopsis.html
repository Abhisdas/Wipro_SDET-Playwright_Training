JavaScript Fundamentals 7 Training Days Async, OOP, DOM, APIs Author: Abhisdas

This repository is a structured 7-day JavaScript training course completed as part of Wipro's SDET (Software Development Engineer in Test) Playwright onboarding program. The curriculum covers JavaScript from absolute basics through advanced asynchronous patterns and Object-Oriented Programming, laying the foundational layer required before transitioning into Playwright test automation. All code is in vanilla JavaScript (Node.js / browser), with no test framework yet — this phase is purely JS proficiency-building.

Core Concepts Covered
Variable Declarations
var (function-scoped, hoisted), let (block-scoped), const (block-scoped, immutable binding) — and why var is avoided in modern JS.
Array Higher-Order Fns
filter(), map(), reduce(), forEach(), find(), splice(), push/pop/shift/unshift, chaining patterns.
Asynchronous JS
Callback functions → Promises (resolve/reject) → .then()/.catch() chains → async/await with try/catch. Event loop awareness via setTimeout/setInterval.
Fetch & REST APIs
Browser fetch() for GET requests, JSON parsing with res.json(), chaining data transformations post-fetch, handling multiple APIs in a single async function.
ES6 Classes & OOP
Class syntax, constructors, private fields (#field), method definitions, encapsulation, extends + super() for inheritance, method overriding for polymorphism, and abstraction patterns.
Prototypal Inheritance
Pre-class prototype patterns: constructor functions, Function.prototype, Object.create(), prototype chain lookup, hasOwnProperty().
DOM Manipulation
document.getElementById(), reading .value from inputs, inline onclick event handlers, window.location.href for navigation, and alert().
Type System & Coercion
typeof, explicit conversion with Number(), String(), parseInt(), parseFloat(), loose vs strict equality (== vs ===), isNaN().
JSON Handling
JSON.stringify() to serialize objects to strings, JSON.parse() to deserialize, using JSON for API response processing and structured output.

Callback + Promise pattern — Day 6 applyPromo()

const isEligible = (p) => p.category === "Electronics" && p.price > 200; function applyPromo(cart, promoCallback) { return new Promise((resolve) => { const updated = cart.map(item => { if (promoCallback(item)) { item.price *= 0.9; item.isDiscounted = true; } else item.isDiscounted = false; return item; }); setTimeout(() => resolve(updated), 1000); // simulated server delay }); }
