Phase 1 — JS Foundations

Core JavaScript from variables to closures, OOP, async patterns, and debugging. 11 days of building confidence in the language before any framework.

Days 1 – 11

Phase 2 — Advanced JS + TypeScript

Modern ES6+ features, destructuring, OOP patterns, and a full TypeScript introduction — type annotations, interfaces, and converting JS to TS.

Days 12 – 13

Phase 3 — Playwright Hands-On

End-to-end Playwright coverage: locators, actions, POM, API testing, visual testing, CI/CD, and AI-assisted test generation with MCP and GitHub Copilot.

Days 14 – 25
