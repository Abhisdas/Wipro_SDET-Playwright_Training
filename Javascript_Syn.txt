JavaScript uses let, const, and var to declare variables. let is block-scoped, const cannot be reassigned, and var is function-scoped.

let name = "Abhishek";
const age = 22;
var city = "Bihar";

JavaScript is dynamically typed, meaning variables can hold different types of data such as string, number, and boolean.

let str = "Hello";
let num = 10;
let bool = true;

Strings can be manipulated using built-in methods like length, uppercase, lowercase, and substring.

let str2 = "Hello World";
console.log(str2.length);
console.log(str2.toUpperCase());
console.log(str2.substring(0,5));

JavaScript supports basic mathematical operations like addition, subtraction, multiplication, and division.

let a = 5;
let b = 10;
console.log(a + b);
console.log(a * b);

Comparison and logical operators are used to compare values and return boolean results.

console.log(a > b);
console.log(a == b);
console.log(a != b);

Objects store data in key-value pairs and allow structured data handling.

let obj = {
    name: "Alice",
    age: 30
};
console.log(obj.name);

Functions are reusable blocks of code used to perform specific tasks.

function add(a, b) {
    return a + b;
}
console.log(add(5, 10));

Arrow functions provide a shorter syntax for writing functions.

const sum = (x, y) => x + y;
console.log(sum(5, 10));

Arrays are used to store multiple values in a single variable.

let arr = [1, 2, 3, 4];
console.log(arr[0]);

Array methods like push, pop, shift, and unshift help in modifying arrays.

let colors = ["red", "blue"];
colors.push("green");
colors.pop();

Higher-order functions like filter, map, and forEach simplify array operations.

arr.filter(x => x > 2)
   .map(x => x * 2)
   .forEach(x => console.log(x));

Loops are used to repeat a block of code multiple times.

for(let i = 0; i < 5; i++) {
    console.log(i);
}

Conditional statements execute code based on given conditions.

if(a > b) {
    console.log("a is greater");
} else {
    console.log("b is greater");
}

Switch statements are used for handling multiple conditions.

let choice = "A";
switch(choice) {
    case "A":
        console.log("Choice A");
        break;
    default:
        console.log("Invalid");
}

Template literals allow easy string formatting using backticks.

let user = "Aryan";
console.log(`Hello ${user}`);

JavaScript supports type conversion between strings and numbers.

console.log(Number("5"));
console.log(String(10));

parseInt and parseFloat convert string values into numbers.

console.log(parseInt("10.5"));
console.log(parseFloat("10.5"));

The Math object provides useful mathematical functions.

console.log(Math.random());
console.log(Math.floor(4.9));

The typeof operator is used to check the type of a variable.

let value = 10;
console.log(typeof value);

JavaScript can interact with HTML elements using DOM manipulation.

const input = document.getElementById("namebox");
console.log(input.value);

Event handling allows JavaScript to respond to user actions.

<button onclick="submit()">Submit</button>

JavaScript can collect user input and interact with web pages dynamically.

function submit() {
    const name = document.getElementById("namebox");
    console.log(name.value);
}

The Fetch API is used to get data from external sources (APIs).

fetch("https://dog.ceo/api/breeds/image/random")
  .then(res => res.json())
  .then(data => console.log(data.message));

Async/Await is a modern way to handle asynchronous operations.

async function getData() {
    const res = await fetch("https://catfact.ninja/fact");
    const data = await res.json();
    console.log(data.fact);
}
getData();

Advanced array processing combines multiple concepts like filter and map.

const numbers = [1, "A", 5, 10];

const result = numbers
    .filter(x => typeof x === "number")
    .map(x => x * 2);

console.log(result);
