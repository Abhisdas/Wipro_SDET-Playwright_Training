JavaScript uses let, const, and var to declare variables. let is block-scoped, const cannot be reassigned, and var is function-scoped.

let name = "Abhishek";
const age = 22;
var city = "Bihar";

JavaScript is dynamically typed, meaning variables can hold different types of data such as string, number, and boolean.

let str = "Hello";
let num = 10;
let bool = true;

Strings can be manipulated using built-in methods like length, uppercase, lowercase, and substring.

let str2 = "Hello World";
console.log(str2.length);
console.log(str2.toUpperCase());
console.log(str2.substring(0,5));

JavaScript supports basic mathematical operations like addition, subtraction, multiplication, and division.

let a = 5;
let b = 10;
console.log(a + b);
console.log(a * b);

Comparison and logical operators are used to compare values and return boolean results.

console.log(a > b);
console.log(a == b);
console.log(a != b);

Objects store data in key-value pairs and allow structured data handling.

let obj = {
    name: "Alice",
    age: 30
};
console.log(obj.name);

Functions are reusable blocks of code used to perform specific tasks.

function add(a, b) {
    return a + b;
}
console.log(add(5, 10));

Arrow functions provide a shorter syntax for writing functions.

const sum = (x, y) => x + y;
console.log(sum(5, 10));

Arrays are used to store multiple values in a single variable.

let arr = [1, 2, 3, 4];
console.log(arr[0]);

Array methods like push, pop, shift, and unshift help in modifying arrays.

let colors = ["red", "blue"];
colors.push("green");
colors.pop();

Higher-order functions like filter, map, and forEach simplify array operations.

arr.filter(x => x > 2)
   .map(x => x * 2)
   .forEach(x => console.log(x));

Loops are used to repeat a block of code multiple times.

for(let i = 0; i < 5; i++) {
    console.log(i);
}

Conditional statements execute code based on given conditions.

if(a > b) {
    console.log("a is greater");
} else {
    console.log("b is greater");
}

Switch statements are used for handling multiple conditions.

let choice = "A";
switch(choice) {
    case "A":
        console.log("Choice A");
        break;
    default:
        console.log("Invalid");
}

Template literals allow easy string formatting using backticks.

let user = "Aryan";
console.log(`Hello ${user}`);

JavaScript supports type conversion between strings and numbers.

console.log(Number("5"));
console.log(String(10));

parseInt and parseFloat convert string values into numbers.

console.log(parseInt("10.5"));
console.log(parseFloat("10.5"));

The Math object provides useful mathematical functions.

console.log(Math.random());
console.log(Math.floor(4.9));

The typeof operator is used to check the type of a variable.

let value = 10;
console.log(typeof value);

JavaScript can interact with HTML elements using DOM manipulation.

const input = document.getElementById("namebox");
console.log(input.value);

Event handling allows JavaScript to respond to user actions.

<button onclick="submit()">Submit</button>

JavaScript can collect user input and interact with web pages dynamically.

function submit() {
    const name = document.getElementById("namebox");
    console.log(name.value);
}

The Fetch API is used to get data from external sources (APIs).

fetch("https://dog.ceo/api/breeds/image/random")
  .then(res => res.json())
  .then(data => console.log(data.message));

Async/Await is a modern way to handle asynchronous operations.

async function getData() {
    const res = await fetch("https://catfact.ninja/fact");
    const data = await res.json();
    console.log(data.fact);
}
getData();

Advanced array processing combines multiple concepts like filter and map.

const numbers = [1, "A", 5, 10];

const result = numbers
    .filter(x => typeof x === "number")
    .map(x => x * 2);

console.log(result);

JavaScript Learning Synopsis
Day 1 – Introduction to JavaScript and Basics

JavaScript is a high-level, interpreted programming language mainly used to make web pages interactive. It works alongside HTML (for structure) and CSS (for styling). Every browser has its own engine (like Chrome’s V8) that executes JavaScript code.

In programming, variables are first declared and then assigned values. Declaration means creating a variable, while initialization means giving it a value. Both can also be done together in one line.

JavaScript provides three keywords to declare variables: var, let, and const. The var keyword is function-scoped, while let and const are block-scoped (limited to {}). Additionally, const cannot be reassigned once defined.

JavaScript runs in browsers, but outside the browser, we use Node.js, which is a runtime environment that allows JavaScript to run on servers. JavaScript is generally used for client-side operations, meaning it runs on the user’s device.

One important concept is client-server communication. The client sends a request to a server (usually through HTTP/HTTPS), and the server responds with data. This data is often in JSON format, which is simply a structured way of storing data in key-value pairs.

Once a request is completed, the connection is closed. The request-response cycle has three main states: pending (processing), successful (completed), and failed (error occurred). Common errors include codes like 404 (not found) and 500 (server error). For example, login operations usually use POST requests instead of GET.

We also practiced string operations such as finding length, converting case, and extracting parts of strings. JavaScript supports arithmetic operations like addition, subtraction, multiplication, division, and modulus. Logical and comparison operators help in making decisions by returning true or false.

Objects in JavaScript store related data in key-value pairs and allow easy access to properties. We also explored loops such as for, while, and do-while, which are used to repeat tasks. The typeof operator helps identify the type of any variable.

Day 2 – Advanced JavaScript Concepts

We began with template literals, introduced in ES6. These use backticks (`) and allow embedding variables directly inside strings using ${}. This makes string handling cleaner compared to traditional concatenation.

Functions were explored further, including arrow functions. Arrow functions provide a shorter syntax and are commonly used in modern JavaScript for cleaner code.

We worked with arrays and powerful methods like filter, map, and forEach.

filter() is used to select specific elements based on a condition.
map() transforms each element into a new value.
forEach() is used to iterate through elements.

We also studied random number generation using Math.random(), which gives values between 0 and 1. By combining it with Math.floor(), we can generate random integers within a range.

Other Math functions include:

Math.floor() → rounds down
Math.ceil() → rounds up

Type conversion is another important concept. JavaScript allows conversion between string and number using functions like Number() and String(). Additionally, parseInt() converts to integer, while parseFloat() keeps decimal values.

Array operations such as push, pop, shift, and unshift help modify arrays. We also explored indexOf, includes, and length for searching and accessing data.

The splice() method allows adding or removing elements from specific positions in an array.

One of the most powerful methods we learned is reduce(). It processes an array and returns a single value, such as the sum of elements. It uses an accumulator and a current value to compute results step by step. It can also be used for advanced tasks like counting occurrences of elements.

Day 3 – Practical Implementation

We applied the learned concepts by building a simple login page using HTML, CSS, and JavaScript. This helped in understanding how JavaScript interacts with web pages and handles user input.

Day 4 – Asynchronous JavaScript

Asynchronous programming allows JavaScript to perform tasks without blocking execution. This is useful for operations like API calls or timers.

Promises are used to handle asynchronous tasks. A Promise has three states:

Pending
Resolved (fulfilled)
Rejected

We used .then() to handle successful results and .catch() for errors.

Functions like setTimeout() execute code after a delay, while setInterval() runs code repeatedly after fixed intervals.

We also explored the fetch() function, which is used to request data from APIs. It returns a Promise, which can be processed step-by-step using chaining. Data received is usually converted into JSON, filtered, modified, and then displayed.

This demonstrated how JavaScript efficiently handles external data while maintaining smooth execution.

Day 5 – Async/Await and OOP

The async and await keywords provide a cleaner way to work with asynchronous code compared to .then().

async defines a function that returns a Promise
await pauses execution until the Promise is resolved

This makes asynchronous code look similar to synchronous code and improves readability.

We also covered Object-Oriented Programming (OOP), which organizes code into reusable structures.

Key OOP concepts include:

Class → blueprint for objects
Object → instance of a class
Methods → functions inside a class
Properties → variables inside a class

Main principles of OOP:

Encapsulation → restricting direct access to data
Inheritance → deriving one class from another
Polymorphism → same function behaving differently
Abstraction → hiding complex logic and showing only essentials

OOP helps in writing structured, reusable, and maintainable code, especially in large applications.
